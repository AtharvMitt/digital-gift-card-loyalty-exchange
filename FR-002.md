ID: FR-002
Type: Functional
Description: The system shall convert validated loyalty points into universal exchange credits using the currently applicable dynamic conversion rate.
Priority: High
Acceptance Criteria: Pass: Valid points are converted using the current conversion rate and the resulting credit balance is updated. Fail: Conversion is rejected when the points are invalid or the conversion rate is unavailable.
Rationale: Users need a common exchange unit to redeem gift cards across participating merchants.
